# PRD-005: `gyeoldaero serve`

## Problem

The output directory needs to be reachable from a phone over the tailnet, safely, with
one command that can run as a service on watchtower.

## Outcome

`gyeoldaero serve [PATH]` builds, watches and serves the notebook. Ellie runs it as a systemd
user service on watchtower and reads her notes from her phone.

## Scope

- axum server over the output directory with the headers in `architecture.md` → *Serving*.
- `--bind`, `--out` flags and `[serve]` config.
- Graceful shutdown on SIGINT/SIGTERM.
- Docs: running under systemd, exposing over Tailscale (`tailscale serve`), and a Syncthing
  note.

## Non-goals

- Authentication (the tailnet is the boundary).
- TLS termination inside gyeoldaero (Tailscale or a reverse proxy does it).
- Live reload.

## Requirements

1. Default bind `127.0.0.1:4321`. Print the URL on startup.
2. Serve only from the output directory; `/` serves the root page; unknown paths return a
   small styled 404 page generated by the renderer.
3. Headers: `Content-Security-Policy: default-src 'self'; img-src 'self'; style-src 'self';
   script-src 'self'; font-src 'self'; object-src 'none'; base-uri 'none';
   frame-ancestors 'none'`, `X-Content-Type-Options: nosniff`,
   `Referrer-Policy: no-referrer`. `Cache-Control: no-cache` on HTML,
   long-lived on hashed `_gyeoldaero/` assets.
4. Ship `contrib/systemd/gyeoldaero.service` (user unit) and document it in the README.
5. README section "Reading from your phone" walking through the reference setup in the
   bible: Syncthing → watchtower → `gyeoldaero serve` → `tailscale serve`.

## Acceptance criteria

- [ ] AC1 — Requests for every fixture page return 200 with the required headers. *(integration)*
- [ ] AC2 — Path traversal attempts (`/../`, encoded variants, absolute paths) never escape
      the output dir. *(integration)*
- [ ] AC3 — A note edited on disk is visible on reload within 2 s while serving. *(integration)*
- [ ] AC4 — SIGTERM shuts down cleanly with exit code 0. *(integration, unix)*
- [ ] AC5 — The e2e suite runs against `gyeoldaero serve` instead of a generic static server. *(e2e)*
- [ ] AC6 — Ellie has run it on watchtower via the systemd unit and opened it from her
      phone. *(by hand — record in the PR)*
